Engineering philosophy

Designed to support human decisions, not replace them.

False confidence is an IAM risk of its own. A failed connector, partial export or missing record must never silently turn into evidence that access was safely removed.

01 · Read-only operations

No scripts approve, provision, disable or revoke permissions as part of analysis.

02 · Evidence before conclusions

Incomplete sources, missing entitlements and collection failures are explicit exceptions.

03 · Repeatable verification

Pinned sample data, Pester tests and GitHub Actions make results inspectable.

Try it locally

Start with synthetic data.

Clone an individual repository, open a PowerShell 7.2+ terminal at its root, then use that repository's demo command. Example for the AD/LDAP analyzer:

./Invoke-AdExceptionAnalyzer.ps1 -Mode Csv `
  -AsOfUtc '2026-11-05T12:00:00Z'

Open the generated report in output/. Compare it with the fixture description in DEMO.md. No production connection is necessary. These are evaluation tools, not compliance certification or production-ready remediation systems. Never publish real account data or audit exports.
